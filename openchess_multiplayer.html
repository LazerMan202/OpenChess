How it works
  1. One person clicks Create room.
  2. Send the room code to your opponent.
  3. They enter it and click Join room.
  4. White moves first. The host is White.

Both players need internet and must keep the page open. This uses PeerJS's public signaling service; connection availability depends on that service and the players' networks.
